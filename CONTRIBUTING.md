# Contributing to HIM

Thank you for your interest in Home Infrastructure Manager.

The project is in its early planning phase. Please open an issue before embarking on a substantial change so that the scope and proposed interfaces can be discussed first.

## Guidelines

- Keep the target audience in mind: small home networks, not enterprise fleets.
- Favor small, independently testable components and simple, documented interfaces.
- Preserve read-only inventory behavior. Changes to a managed host must be explicit, logged and permission-limited.
- Include tests or reproducible validation steps for behavioral changes.
- Avoid introducing unnecessary dependencies.
- Do not include real inventories, machine identifiers, credentials, tokens or other personal data in issues, tests, logs or commits.

## Licensing contributions

Unless explicitly stated otherwise, any contribution intentionally submitted for inclusion in HIM is submitted under **MIT OR Apache-2.0**, at the recipient's option.

By submitting a contribution, you confirm that you have the right to license it on those terms. If a contribution contains third-party code or assets, clearly identify their source and license; do not assume they can be relicensed.

We may request clarification before accepting a contribution.

## Development setup

The initial implementation and development workflow are not finalized. Setup and test instructions will be added as the first components are introduced.
